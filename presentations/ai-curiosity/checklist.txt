회사 발표 PC — 5분 점검

□ 공개 발표 URL을 GPT에 접속하지 않은 일반 Chrome/Edge 창에서 열기.
□ GitHub Pages가 막히면 ZIP 전체를 풀고 index.html 더블클릭.
□ F 전체화면, ←→ 이동, N 노트, O 목록, Esc 복귀 확인.
□ 13번 운전 영상의 10초 재생과 16번 댐핑 애니메이션 재생 확인.
□ 28번 REA ‘다음 단계’ 버튼으로 6단계 전환 확인.
□ 웹앱 실시간 시연을 열고 Boxer 검색·지도·출처·최근 이슈 확인.
□ 3D는 이 PC에서 별도로 확인. 안 열리면 4번의 실제 실패 화면에서 구현 범위만 설명하고 넘어가기.
□ 두 번째 모니터를 쓸 때 발표자 창이 청중에게 보이지 않는지 확인.
□ 회사망의 원문 사이트·지도 타일 접속은 이 PC에서 직접 확인.
□ 최종 백업 PDF를 한 번 열어 두기. 영상은 정지 장면으로 대체됨.

빠른 대체 동선
실시간 웹앱 실패 → Esc → 2~7번 캡처 또는 8번 ‘다음 캡처’.
외부 영상 실패 → 포함된 로컬 영상 사용. 그것도 불가하면 PDF의 정지 장면으로 설명.
전체 HTML 실패 → 백업 PDF로 진행. 애니메이션을 실제 모델 활동으로 바꾸어 말하지 않기.

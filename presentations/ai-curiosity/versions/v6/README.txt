ZIP 전체를 압축 해제한 뒤 V6/index.html을 Chrome 또는 Edge에서 엽니다.
포인터 다음/이전 버튼과 화면 아래 화살표가 동일하게 작동합니다.
- 일반 장표: 다음/이전 장표로 이동
- REA·CAN·게임 설명·처리 흐름·저장 화면: 같은 장의 단계부터 이동, 마지막 단계에서 다음 장표
- 영상·댐퍼: 다음 버튼으로 재생, 한 번 더 누르면 다음 장표
- 이전 장표로 돌아가면 그 장의 마지막 단계부터 되짚기
- 키보드: PageDown/PageUp, 방향키, Space/Shift+Space, Enter/Backspace
- 장표 바로 이동: Shift+방향키 · Home/End: 처음/끝
- F: 전체화면 · O: 목록 · N: 노트 · S: 출처 · A: 애니메이션 재생/정지

포인터가 위 표준 키를 보내는 경우 별도 설치 없이 사용할 수 있습니다.
발표 전에 실제 포인터로 다음·이전과 영상 재생을 한 번 확인하세요.
인터넷 없이 포함 영상과 애니메이션, 대본이 작동하도록 구성했습니다.
실제 웹앱 시연과 원출처 링크에는 인터넷이 필요합니다.
실제 웹앱 안으로 포커스가 이동하면 발표로 돌아가기 버튼으로 복귀합니다.

V1·V2·V3·V4·V5는 이전 버전으로 그대로 보존했습니다. 버전별 주소를 열면 바로 롤백할 수 있습니다.

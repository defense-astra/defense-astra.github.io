발표 직전 5분 확인
1. 발표 PC에서 index.html 또는 V2 공개 주소를 엽니다.
2. 13장 운전 영상, 37장 게임 결합 영상을 재생합니다.
3. 16장 댐퍼, 28장 REA, 34장 CAN, 38장 게임 연결 재생을 확인합니다.
4. 웹앱 3D를 실제 PC에서 확인합니다. 안 되면 4장을 짧게 설명하고 저장한 화면으로 넘어갑니다.
5. 8장에서 한 번의 연속 웹앱 시연을 합니다. 앞 1~7장은 기능 개요로만 진행합니다.
6. 두 번째 모니터가 있으면 N → 별도 발표자 창을 엽니다.
7. 문제가 생기면 PDF, 또는 버전 기록에서 V1으로 돌아갑니다.

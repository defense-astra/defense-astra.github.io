발표 V2 검수 기록 · 2026-10-18

- 40장, 배정 합계 1800초. 목표 진행표이며 실시간 리허설 결과는 아닙니다.
- 사용자 입력 6개를 띄어쓰기까지 보존. 빈칸 189개는 추천 채택 후, REA·CAN 등 구조 개편에 따른 재구성을 적용 기록에 구분.
- 공개 검수 경로에서 40개 장표 렌더링, 한국어 줄바꿈·이미지·배치 검토.
- REA 6개 장면×4단계의 조작 및 근거 표기 확인, 자동 재생 마지막 단계 정지 확인.
- CAN 4단계 단위 변환, 선택 구간, 최종 보고서 확인. JS·Python 독립 계산 결과 일치.
- 게임 원본 5.1초 영상 정상 종료(readyState4, mediaerror없음). 원리 도식 3단계·재생·정지·화면 버튼 확인.
- 신경망·댐퍼 그림은 설명용 합성 애니메이션이며 실제 신경 활동·차량 성능 검증이 아닙니다.
- REA·FlyVis·외부 게임 프로젝트는 제작자 자료와 공식 문서/코드를 대조했으며 이번 작업에서 외부 실험을 재실행한 것은 아닙니다.
- 모든 자산 경로, JS 구문, 사용자 6개 문구, 30분 배정표, V1 원본 50파일의 SHA-256 보존 검증.
- 정적 발표 build 및 기본 버전 v1→v2 전환 명령 통과. 앱 코드에는 변경이 없습니다.

- 댐퍼 재생 시간 증가, 노트 열 때 일시정지와 버튼 동기화 확인. 발표자 창 실행 확인.
제약
- 검수 브라우저에서 장비 웹앱 WebGL 3D는 표시되지 않았습니다. 실제 발표 PC 확인이 필요합니다.
- 회사망·실물 모바일·발표 PC·file:// 직접 실행은 미확인. 로컬 자산 패키지는 상대경로 및 fetch/CDN 불필요 구조로 검사.
- 로컬 미리보기 supervisor는 bwrap/proc 권한 오류. 별도 공개 검수 경로에서 브라우저 검사를 수행했습니다.

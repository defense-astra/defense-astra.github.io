발표 자료 V2 변경 기록
2026-10-18

전체 구성
- 기존 32장에서 40장으로 확장했습니다. 웹앱 소개 → 초파리와 댐퍼 → REA → CAN 업무 응용 → 게임 결합 사례 → 사용 안내와 질의응답 순서입니다.
- 발표 시간은 질의응답을 포함해 30분으로 배정했습니다. 실제 발표 속도를 측정한 결과가 아니라 진행 계획입니다.

문구 반영
- 수정 양식의 기존 문구 195개를 검토했습니다.
- 사용자가 직접 입력한 6개 문구는 원문 그대로 반영했습니다.
- 빈칸 189개는 추천 문구를 기준으로 반영했습니다. 새 애니메이션과 달라진 장표 구성에 맞춰 일부 문구는 재작성하거나 합쳤습니다. 195개 모두를 글자 그대로 복사했다는 뜻은 아닙니다.
- 추가된 8장과 새 애니메이션 세부 문구는 별도로 작성했습니다.

화면과 시연
- 실제 웹앱 화면을 크게 보여주도록 배치를 바꿨습니다. 기능을 짧게 소개한 뒤 한 번의 연속 시연으로 이어갑니다.
- 댐퍼 장면은 요철, 바퀴와 댐퍼, 설명용 신호의 관계를 따라볼 수 있게 다듬었습니다. 실제 초파리 신경 활동이나 실차 성능 결과로 소개하지 않습니다.

REA 설명
- 기존 한 장의 도식을 연결 도구, 필요한 부분 조회, 분석 상태 유지, 도구 호출, 근거 기록, 실행 결과 비교의 여섯 장면으로 확장했습니다.
- 분석 기계와 AI 연구자 삽화는 이번 발표용으로 새로 생성했습니다. 참고 영상의 그래픽을 추출해 사용한 파일이 아닙니다.
- 고정된 API 개수, 모든 분석에 걸리는 시간, 환각의 완전 차단 같은 확인되지 않은 표현을 사용하지 않습니다.

CAN 응용
- 합성 데이터에서 필요한 채널을 고르고, 시간축과 단위를 맞추고, 조건에 맞는 구간을 추출해 그래프와 수치가 담긴 보고서로 연결합니다.
- 화면의 데이터는 설명용이며 실제 회사 로그를 포함하지 않습니다.

게임 결합 사례
- Minecraft와 GTA V를 연결한 Universal Modder 사례를 추가했습니다. 제작자가 공개한 영상의 첫 5.1초와 별도로 만든 원리 애니메이션을 함께 보여줍니다.
- 카메라 맞추기, 색·깊이 합성, 사건 전달을 세 단계로 설명합니다. REA로 제작됐다고 확인된 사례로 소개하지 않습니다.
- 영상은 같은 발췌 구간을 H.264 CRF 25로 다시 압축해 용량을 줄였습니다. 각 게임 자산의 권리는 해당 권리자에게 있습니다.

버전 구분
- 이 자료는 V2 개정본입니다. 기존 버전과 구분해 보관하고, 배포 이력과 이전 버전으로 돌아가는 방법은 함께 제공하는 버전 기록을 기준으로 확인합니다.

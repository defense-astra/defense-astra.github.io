# V7 시야각 검토 통합

원본 공개 앱: https://qkfhvnfrl-ux.github.io/defense-trends-web/afv-8x8-lab/
원본 공개 커밋: 8225747e34e8eee1e4dab8039d86d6850ded75f8 (2026-11-10 사진 수정본).

이 디렉터리는 위 공개 앱의 사진 수정본을 기반으로 합니다. 원본 사진·라이선스·사진 크레딧을 유지하고, 스튜디오에 축척·길이·지상고 측정, 공개 제원 기준 입력 및 PDF 저장을 추가했습니다. V7은 `/sightline` 탭에서 이 앱을 같은 출처 iframe으로 표시합니다.

기존 사이트와 origin이 다르므로 브라우저 자동 저장 기록은 이전 사이트에서 JSON으로 내보낸 후 이 앱에서 가져와야 합니다. 기록 및 업로드한 사진은 사용자 브라우저에 저장되며 별도 서버 업로드는 없습니다.

## 축척·길이 기능 추가 · 2026-11-10

1. ‘축척 기준’으로 실제 길이를 아는 구간을 지정하고, 실제 길이를 mm·cm·m로 입력합니다.
2. ‘길이’는 두 점의 직선거리를 mm로 표시합니다. ‘지상고’는 지면 기준선을 그린 뒤 선택한 차체 하단 점까지의 수직거리를 계산합니다.
3. 기준 구간·실제 길이·지면 기준선을 변경하면 기존 측정값이 다시 계산됩니다. 축척은 차량별로 관리되며 사진 교체 시 초기화됩니다.

타이어 예시는 규격상의 기하 계산값입니다. 인치 림은 `림 지름×25.4 + 2×단면폭×편평비/100`, 알려진 mm 림(R560/R685)은 `림 지름 + 2×단면폭×편평비/100`을 사용합니다. `14.00 R20`처럼 편평비가 없는 표기는 외경을 자동 추정하지 않습니다. 정확한 해당 제품 외경을 알고 있다면 직접 입력한 값을 우선 사용하세요.

같은 평면의 기준 길이를 사용해야 합니다. 원근·렌즈 왜곡·타이어 하중변형을 보정하지 않으므로 사진상 추정값으로 사용하며, 실제 시야각·공인 지상고와 구분합니다.

프로젝트 JSON은 V2로 저장하고 V1·V2를 가져옵니다. 기존 V1 각도 기록은 유지하며, V2에는 축척 기준의 실제 길이·입력 근거와 길이·지상고 기록이 포함됩니다. PNG와 CSV에도 축척과 측정값을 제공합니다.

계산 검증: `node --test scripts/test-sightline-measurement.mjs`의 12개 테스트 및 독립 Node VM 상태·V1/V2 호환 검증 통과. 브라우저·전체 빌드·배포 검증은 저장소 EVIDENCE.md의 해당 작업 기록을 확인하세요.

## 공개 제원으로 축척 설정 · 2026-11-10

1. 차량을 선택하고 ‘공개 차량 제원으로 기준 길이 선택’에서 높이·전장·전폭을 고릅니다. 10차종 33개 치수 중 높이 14개를 먼저 나열합니다.
2. 해당 값의 기준점·차량 형식·출처와 조건을 확인하고 ‘선택 제원 넣기’를 누릅니다. 높이의 차체 상단·포탑 지붕·무장 포함 범위를 사진과 맞추세요.
3. 사진에서 같은 기준점 사이를 ‘축척 기준’으로 지정합니다. 이미 구간을 그렸다면 끝점이 맞는지 확인한 뒤 ‘기준 길이 적용’을 누릅니다. 값과 입력 근거는 차량별 축척 기록에 저장됩니다.
4. ‘길이’ 또는 ‘지면 기준선’과 ‘지상고’ 도구로 측정합니다. 기준을 바꾸면 기존 결과가 다시 계산됩니다.

높이가 항상 더 정확한 기준은 아닙니다. 같은 평면에서 끝점이 명확하고 충분히 긴 기준 구간을 사용하세요. 사진의 형식·적재/현가 상태·원근이 다르면 공개 높이도 오차를 만들 수 있습니다. `limited`는 자료 불일치, 기준점 미명시 또는 적용 조건 확인이 필요하다는 뜻이며, `verified`도 사진에 그대로 적용할 수 있다는 보장은 아닙니다. 전폭은 정면·후면에 가까운 사진에서 사용하고 측면의 투영 폭에 적용하지 마세요. 확정되지 않은 상한값을 정확한 기준 길이로 제공하지 않습니다.

## 측정 PDF 직접 저장 · 2026-11-10

- 상단 ‘측정 PDF 저장’은 스튜디오에 표시 중인 차량 1대 또는 2대를 저장합니다. 사진 아래 ‘PDF 저장’은 그 차량 한 대만 저장합니다.
- PDF에는 전체 사진과 주석, 측정 기록, 축척·입력 근거, 공개 제원·적용 조건, 자료 출처와 사진 크레딧을 포함합니다. 화면 확대·이동은 출력 구도에 영향을 주지 않으며 좌우 반전 상태는 반영합니다.
- 브라우저 안에서 A4 가로 PDF를 생성해 직접 다운로드합니다. 별도 서버 전송이나 인쇄 대화상자는 사용하지 않습니다. 긴 기록과 출처는 여러 페이지로 나눕니다.
- 한글을 포함한 페이지를 이미지로 담으므로 본문 검색·텍스트 복사·출처 링크 클릭은 지원하지 않습니다. 기록을 다시 편집하려면 ‘프로젝트 저장’으로 JSON도 보관하세요. JSON V2 저장과 기존 V1 가져오기는 유지됩니다.
- 사진이 아직 로딩 중이면 완료 후 다시 저장하도록 안내하며, 생성 중 중복 저장을 막습니다. 사용자 사진에는 업로드 사진명과 사용자 사진 안내를 넣고 수집 원본 사진의 출처를 제외합니다.

검증 상태: Vitest 33개, `node --test scripts/test-sightline-measurement.mjs scripts/test-sightline-pdf.mjs` 19개, 자료 검사 및 공개 빌드 통과. 독립 VM/jsdom 11개 그룹에서 제원 선택·근거·차량별 독립성·undo/redo·V1/V2, 패널별 PDF 데이터, 실제 스냅샷 좌표와 오류 복구를 확인했습니다. 실제 브라우저 PDF 다운로드·파일 렌더 및 공개 배포 검증은 진행 중입니다.

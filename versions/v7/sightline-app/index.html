각도 측정 사용 방법

01

차량과 사진 선택

왼쪽 목록에서 차량을 선택합니다. 더 정확한 정측면 사진이 있다면 ‘내 사진’을 불러오세요.

02

기준선 지정

‘기준선’ 도구로 사진 속 지면을 따라 두 점을 찍습니다. 직선 각도는 이 기준선에 대해 계산됩니다. 미지정 시 이미지 수평선 기준입니다.

03

선·각도 표시

‘직선 각도’는 두 점 클릭 또는 드래그, ‘세 점 각도’는 끝점 → 꼭짓점 → 끝점 순서로 클릭합니다. ‘눈 위치’는 사용자가 추정한 점을 표시합니다.

04

편집·비교·저장

‘선택’ 도구에서 기록을 클릭하고 끝점을 드래그해 수정하세요. 사진 PNG와 프로젝트 JSON을 저장할 수 있습니다. 프로젝트에는 측정값과 내 사진이 포함됩니다.

직선 각도: 기준선에 대한 작은 각 0–90°. 세 점 각도: 꼭짓점의 내각 0–180°. 원근 보정이나 실제 시야각 산출 기능은 아닙니다. Esc: 그리기 취소 · Delete: 선택 삭제 · Ctrl/Cmd+Z: 실행 취소.
